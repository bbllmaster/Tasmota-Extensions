通用规则面板

← 返回设备主页
每条规则 = 触发器 ON <触发事件> + 命令 DO <任意 Tasmota 命令>，拼为 ON … DO … ENDON。
支持所有触发器类型：按钮/开关、电源、系统事件、时间、MQTT、传感器、自定义 Event 等；模板下拉仅作快捷填充，可直接编辑。
命令支持所有 Tasmota 命令（publish / Power / Backlog / Var1 / RuleTimer 等），可用 %value% 引用触发值。
保存后立即生效，写入 Rule1/2/3（会整体重写这三个槽）。注意：与 /btns 按钮面板共用同一套规则槽，请勿在两个页面分别保存。
示例：触发器 Time#Minute=241 + 命令 publish cmnd/tasmota_fy1_81743B/POWER TOGGLE → 每天 04:01 发送 TOGGLE。
